## 소개

숙명여자대학교 기계시스템학부를 졸업하고, 제어 연구와 로봇 프로젝트를 수행했습니다. 두산로보틱스 인턴으로 자동화 공정 검토에 참여하고, Python 기반 업무 도구를 개발했습니다.

센서 데이터와 제어 로직을 연결해 시스템을 구현하고, 반복 테스트로 동작을 검증하는 일에 관심이 있습니다.

## 관심 직무

| 분야 | 관심 업무 |
| --- | --- |
| 로봇·자율주행 SW | 로봇 제어, 센서 연동 및 시스템 통합 |
| 생산기술·스마트팩토리 | 자동화 설비 제어, 공정 개선 및 로봇 적용 검토 |
| 테스트·검증·품질 | 로봇 성능 평가, 오류 재현 및 데이터 분석 |
| 설비·서비스기술 | 설비 안정화, 현장 문제 분석 및 기술 지원 |

## 대표 프로젝트

### 1. Co-Lab | 인간-로봇 협동 실험실

협동로봇과 중량 센서를 연동한 실험 자동화 프로젝트입니다. 센서 피드백을 활용해 정량 붓기 작업을 제어하고, 작업 상태와 결과를 확인하는 흐름을 구현했습니다.

**담당 역할**

- 팀장으로서 프로젝트 기획과 시스템 통합을 총괄했습니다.
- 로드셀 기반 중량 측정 시스템을 설계하고 ROS2와 연동했습니다.
- 붓기 및 용기 이송 공정을 연결하고, 필터 비교와 제어 파라미터 조정으로 동작을 검토했습니다.

**주요 기술:** Python · ROS2 · Arduino · PD 제어

[프로젝트 코드 보기](https://github.com/kwakmoonjung/Co-Lab)

### 2. DTHRC | 인간-로봇 협업 디지털 트윈

NVIDIA Isaac Sim에서 자동차 조립공정을 재현한 프로젝트입니다. 부품 인식과 이송 작업을 연결하고, 작업자 접근에 따른 감속·정지 동작을 가상환경에서 검토했습니다.

**담당 역할**

- 팀장으로서 프로젝트 기획과 공정 구조 정의를 담당했습니다.
- 인식 결과에 따라 로봇이 작업하고, 작업자 접근 시 안전 동작으로 전환하도록 전체 공정 흐름을 통합했습니다.

**주요 기술:** Python · NVIDIA Isaac Sim · RMPflow · YOLOv8

[프로젝트 코드 보기](https://github.com/kwakmoonjung/DTHRC)

### 3. RoPT | 시니어 운동 코칭 플랫폼

사용자의 운동 자세를 분석하고 협동로봇으로 교정을 보조하는 프로젝트입니다. 사용자 인식부터 운동 기록 관리까지 이어지는 서비스 흐름을 구성했습니다.

**담당 역할**

- 팀장으로서 서비스 기획과 시스템 통합을 총괄했습니다.
- 자세 교정 기능과 운동별 보조 방식을 설계했습니다.
- 로봇 보조 동작과 안전 정지·복귀 기능의 통합 테스트를 수행하고, 기능 간 충돌을 조정했습니다.

**주요 기술:** Python · ROS2 · YOLO Pose · OpenCV

[프로젝트 코드 보기](https://github.com/kwakmoonjung/rehab_assist_robot)
